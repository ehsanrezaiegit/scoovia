# گزارش بازبینی سخت‌گیرانهٔ ZIP — اصلاحیهٔ ۰٫۳٫۱

تاریخ بررسی: ۵ اکتبر ۲۰۲۶. مبنا: ZIP کامل نسخهٔ ۰٫۳٫۰ که قبلاً ارسال شده بود. این گزارش مربوط به بستهٔ قابل‌دانلود است؛ اصلاحات این بررسی در سایت میزبانی‌شده منتشر نشده‌اند.

## نتیجه و اصلاحات

فایل مفقود یا خرابی در ZIP اولیه پیدا نشد. هر ۳۱ فایل، CRC و تمام هش‌های ثبت‌شدهٔ آن درست بودند؛ نام تکراری، مسیر خروج از پوشه، فایل رمزگذاری‌شده و لینک نمادین نداشت. ZIP دریافت‌شده با ZIP ارسال‌شده یکسان بود.

در خواندن کد و اجرای آزمون‌های جدید، دو ایراد واقعی تأیید و اصلاح شد:

۱. نام دلخواهی مثل `constructor` یا `__proto__` در زبان انگلیسی، از اعضای ارث‌رسیدهٔ شیء ترجمه خوانده می‌شد و به متن نادرست تبدیل می‌شد. اکنون فقط کلیدهای خود جدول ترجمه پذیرفته می‌شوند و نام دلخواه متن ساده باقی می‌ماند.

۲. هنگام بازبودن منوی موبایل، تغییر زبان برچسب دسترس‌پذیری دکمه را به «بازکردن منو» برمی‌گرداند. اکنون پس از تغییر زبان، برچسب با وضعیت واقعی منو هماهنگ می‌شود.

دو آزمون جدید ابتدا روی کد اولیه شکست خوردند و پس از اصلاح موفق شدند. فایل `.gitattributes` نیز برای حفظ پایان‌خط LF در انتقال با Git به بسته اضافه شد. تمام تصاویر و فونت‌ها بدون تغییر بایت‌به‌بایت حفظ شده‌اند.

## بررسی‌های انجام‌شده

- صحت نحوی هر پنج ماژول سایت و سرور محلی؛ موفقیت هر ۱۸ آزمون خودکار.
- بررسی ۸٬۲۵۶ ترکیب مجاز بستنی‌ساز: یک تا سه اسکوپ، شش طعم، دو ظرف، چهار انتخاب سس و چهار انتخاب تاپینگ. قیمت، حفظ تنظیمات، ادغام در سبد و تولید متن فارسی و انگلیسی بررسی شدند.
- کنترل شناسه‌های HTML، شناسه‌های مورد استفادهٔ جاوااسکریپت، لینک‌های داخلی، ارجاع‌های ARIA، import ماژول‌ها و URL تصاویر و فونت‌ها در CSS.
- بازکردن کامل چهار فایل WebP؛ کنترل اندازه‌ها و کانال شفافیت. سه تصویر اصلی ۱۰۲۴×۱۵۳۶ و اطلس اسکوپ‌ها ۱۵۳۶×۱۰۲۴ هستند.
- رمزگشایی و خواندن هر چهار فونت WOFF2؛ کنترل وزن‌های ۴۰۰ و ۷۰۰ و وجود حروف فارسی و لاتین. مجوز OFL و لوگوی SVG معتبر داخل بسته‌اند.
- اجرای سرور از پوشه‌ای خارج از پروژه؛ دریافت هر ۱۹ فایل سایت با محتوای صحیح، MIME درست و پاسخ HEAD صحیح. آدرس‌های دو زبان، پاسخ ۴۰۴، رد POST، URL نامعتبر، منع خروج از پوشه، پورت نامعتبر و برخورد پورت بررسی شدند.
- اجرای تابع واقعی رسم کارت برای ۱۲ حالت: دو زبان، دو ظرف و یک تا سه اسکوپ، در ابعاد ۱۰۸۰×۱۹۲۰. نمونهٔ فارسی سه‌اسکوپ و نمونهٔ انگلیسی تک‌اسکوپ با نام `constructor` به‌صورت تصویری بازبینی شدند. برای سازگاری ابزار Canvas محلی، زیرمجموعه‌های دقیق فونت‌ها فقط در محیط بررسی با هم ترکیب شدند؛ فونت‌های پروژه تغییر نکردند. این بررسی، کلیک و دانلود کارت در مرورگر نیست.
- تطابق لینک ایمیل و واتس‌اپ با اطلاعات مالک؛ کنترل UTF-8 و جست‌وجوی الگوهای رایج کلید API و کلید خصوصی، بدون یافتن موردی. این جست‌وجو تضمین تشخیص همهٔ انواع راز نیست.
- استخراج مجدد ZIP نهایی در پوشه‌ای با فاصله در نام؛ کنترل CRC، تمام هش‌ها و اجرای دوبارهٔ بررسی نحوی و ۱۸ آزمون روی محتوای استخراج‌شده.

## اجرای قابل‌تکرار روی لپ‌تاپ

در پوشهٔ استخراج‌شده، با Node.js نسخهٔ ۲۲ یا جدیدتر:

```sh
npm run check
npm test
npm run dev
```

سپس `http://127.0.0.1:3000` را باز کنید. راهنمای آپلود در گیت‌هاب در `START-HERE-FA.md` است. هش‌های فایل‌ها در `SHA256SUMS.txt` و مبنای نسخه و فایل‌های اصلاح‌شده در `EXPORT-INFO.json` ثبت شده‌اند.

## حدود نتیجه

آزمون تعاملی مرورگر، اندازه‌گیری عملکرد، بازبینی تمام صفحات روی موبایل واقعی و اجرای مستقیم روی Windows انجام نشده‌اند. آزمون هماهنگی زبان و منو در محیط واحد با شبیه‌سازی DOM اجرا شده است. صحت فایل و آزمون‌های خودکار، تضمین بی‌نقص‌بودن در همهٔ مرورگرها نیست.

این نسخه همچنان نمونهٔ طراحی است؛ قیمت‌ها نمونه‌اند و سفارش واقعی، پرداخت و backend فروش ندارد. نام برند و دامنه از نظر حقوقی بررسی نشده‌اند. این موارد در نسخهٔ اولیه نیز جزو قابلیت‌های پیاده‌سازی‌شده نبودند.

## اصلاح تکمیلی ۰٫۳٫۲ — سرور محلی ویندوز

ویدئوی لپ‌تاپ نشان داد HTML، CSS و JavaScript اجرا می‌شوند ولی لوگو، تصاویر و فونت‌ها بارگذاری نمی‌شوند. شرط رد بک‌اسلش در مسیر نسبی فایل، روی ویندوز تمام فایل‌های داخل assets را اشتباهاً رد می‌کرد. شرط روی URL ورودی اعمال شد و بررسی خروج از پوشه با جداکنندهٔ سیستم‌عامل انجام می‌شود.

مسیرهای استاندارد ویندوز، پوشه‌های دارای فاصله، مسیرهای POSIX، منع خروج از dist، و دریافت GET/HEAD تمام فایل‌های سایت در سه آزمون جدید پوشش داده شده‌اند. Windows واقعی برای اجرا در اختیار نبود؛ آزمون مسیرهای ویندوز از node:path.win32 استفاده می‌کند. فایل‌های تصاویر، فونت‌ها و رابط سایت با نسخهٔ ۰٫۳٫۱ یکسان مانده‌اند.
